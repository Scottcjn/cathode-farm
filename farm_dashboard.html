Cathode Farm — 1994 AppleTalk Render Cluster

Three emulated Macintoshes running System 7.5, each in its own container, wired onto one virtual EtherTalk segment. Patched Basilisk II accepts input at the ADB layer over a control socket — the Macs are driven from the host like any other service. Snapshot taken live from the running farm.
